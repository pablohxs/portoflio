Sobre mim

Sou Pablo Henrique, desenvolvedor web freelancer baseado em Betim/MG. Trabalho criando sites que funcionam de verdade — rápidos, responsivos e pensados para atender o objetivo de quem encomenda.

Minha abordagem é direta: entender o que o cliente precisa, escolher a solução certa e entregar com qualidade. Crio projetos com HTML, CSS e JavaScript puro, sem dependências desnecessárias, porque acredito que código limpo e leve é a base de qualquer bom site.

Estou em constante evolução, sempre buscando aprender novas tecnologias e aprimorar minha prática. Cada projeto é uma oportunidade de crescer tecnicamente e de ajudar alguém a ter presença digital com qualidade.
